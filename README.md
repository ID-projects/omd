# ДЗ: Функции

В `Corp_Summary.csv` находится выгрузка по сотрудникам: ФИО, департамент,
команда, должность, оценка и оклад. Колонки разделены точкой с запятой (`;`).

Программа читает этот файл и формирует выбранный отчёт. Основная функция
`create_report()` принимает номер варианта:

1. **Иерархия:** для каждого департамента выводит входящие в него команды.
2. **Сводка по департаментам:** выводит количество сотрудников, минимальную,
   максимальную и среднюю зарплату в каждом департаменте.
3. **Сводка в CSV:** сохраняет такую же сводку в CSV-файл.

Чтение файла и формирование каждого отчёта вынесены в отдельные функции.

## Требования

- Python 3
- Дополнительные пакеты не требуются: используются модули стандартной библиотеки.

## Запуск

Поместите `Corp_Summary.csv` рядом с `Solution.py` и запустите:

```bash
python Solution.py
```

По умолчанию формируется отчёт № 3 — сводка по департаментам в
`Department_summary.csv`. Чтобы выбрать другой отчёт, измените аргумент вызова
`create_report()` в конце `Solution.py`:

```python
create_report(1)  # Иерархия департаментов и команд
create_report(2)  # Сводка по департаментам в консоли
create_report(3)  # Сводка по департаментам в CSV
```

Для отчёта № 3 имя выходного файла можно передать вторым параметром после
входного файла, например: `create_report(3, output_file='summary.csv')`.
