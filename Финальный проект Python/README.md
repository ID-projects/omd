# Анализ данных о лауреатах Нобелевской премии

Проект обрабатывает данные о лауреатах Нобелевской премии из локального файла
`laureates.json`. Ноутбук проверяет и преобразует записи о людях и
организациях, проводит первичный анализ данных и рассматривает статистику по
странам, возраст при награждении, гендерное распределение, различия между
страной происхождения и страной первой аффилиации, многократные награждения,
отказы и скорректированные суммы премий. В конце строятся графики по
категориям премий, доле женщин и странам.

## Состав проекта

- `laureates_countries_task.ipynb` — загрузка и анализ данных, вывод
  сводок и построение графиков.
- `laureates.json` — исходные данные.
- `json_dict_processing.py` — общие функции для извлечения значений из
  вложенных словарей и преобразования данных по конфигурации.
- `laureates_configs.py` — конфигурации и обработчики для лауреатов-людей и
  организаций.
- `prizes_configs.py` — конфигурация и обработчик записей о премиях.
- `dataset_helpers.py` — фильтрация, группировка и агрегация записей.
- `aggregations.py` — функции подсчёта, вычисления среднего, медианы,
  максимума и выбора первых записей.
- `attribute_manager.py` — вспомогательный класс для добавления и удаления
  атрибутов в записях.

## Требования

Python 3.10 или новее, VS Code с расширением Jupyter и пакет `matplotlib`
для построения графиков. Файла `requirements.txt` в проекте нет.

## Подготовка окружения

Выполните команды в PowerShell из папки проекта:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install matplotlib ipykernel
```

## Данные

Перед запуском ноутбука поместите `laureates.json` в папку проекта. Ноутбук
читает данные только из этого локального файла и не обращается к API. Если
файл отсутствует или недоступен, загрузка завершится ошибкой.

## Запуск

Чтобы выполнить анализ:

1. Откройте `laureates_countries_task.ipynb` в VS Code.
2. Выберите ядро Python из окружения `.venv`.
3. Выполните все ячейки командой **Run All**.

В ноутбуке есть встроенные `assert`-проверки преобразования и целостности
данных; отдельного набора автоматических тестов в проекте нет. Анализ
миграционных различий сопоставляет страну происхождения (современное
название страны места рождения, если оно доступно) со страной первой
аффилиации первой премии. Аффилиация — лишь приближённый показатель страны,
связанной с премией, а не место жительства лауреата в год вручения; исходный
JSON сведений о месте жительства не содержит. Раздел с бонусным
лингвистическим заданием в ноутбуке содержит условие, но сам анализ текстов
мотиваций не реализован.
