# Решённые задачи

В репозитории собраны решения пяти задач по обработке данных на Python. Каждый файл запускается независимо.

## Установка и запуск

Нужен установленный Python 3. Внешние зависимости отсутствуют: используются только встроенные возможности Python и стандартная библиотека. Устанавливать пакеты через `pip` не требуется.

Проверьте установку Python:

```shell
python --version
```

Запускайте команды из корневой папки репозитория:

```shell
python task_1_solved.py
python task_2_solved.py
python task_3_solved.py
python task_4_solved.py
python task_5_solved.py
```

В Windows вместо `python` можно использовать команду `py`, например `py task_1_solved.py`.

## Описание задач

1. **`task_1_solved.py` — товары на складах.** Находит товары, которые есть в обоих городах или только в одном из них, и считает общее количество разных товаров.
2. **`task_2_solved.py` — история поисковых запросов.** Подсчитывает запросы, находит самый частый, вычисляет его долю и перечисляет запросы, встретившиеся один раз.
3. **`task_3_solved.py` — заказы.** Считает сумму возвратов, покупателей, вернувших заказ, количество доставленных заказов и средний чек доставки.
4. **`task_4_solved.py` — статистика магазина за пять дней.** Считает выручку, находит день с максимальной выручкой, рассчитывает выручку на заказ по дням и отмечает дни с долей возвратов выше 20%.
5. **`task_5_solved.py` — отзывы на товары.** Нормализует названия, считает средние оценки, находит товар с самой низкой средней оценкой среди товаров с несколькими отзывами и анализирует отзывы на 1–2 звезды.

Каждое решение выполняется только при непосредственном запуске файла благодаря блоку `if __name__ == "__main__":`.
